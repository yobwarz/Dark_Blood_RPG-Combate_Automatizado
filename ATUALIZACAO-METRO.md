# Atualização para Metro

Sistema 0.7.1 e API 1.4 acrescentam pontos de controle opcionais para ataques, recargas, destravamento, ataques de criaturas e descanso. Combate Automatizado 0.4.1 respeita ataques cujo custo foi gerenciado pelo cenário. Sem essas opções, as chamadas anteriores conservam seu fluxo. Metro 0.1.0 requer esse núcleo e, se o Combate estiver ativo, a versão 0.4.1.

Regressões do núcleo, Combate, Logística, BSA e cinco expansões anteriores passaram em ambiente simulado. Nenhum dado de personagens, inventário ou regra própria dessas expansões foi migrado por esta atualização. Faça backup e feche o Foundry para substituir os pacotes.
